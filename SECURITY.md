# Security

This repository is the outflare.ai website and docs. The product's own code, and most security reports, belong in [outflareai/outflare](https://github.com/outflareai/outflare/security).

Please do **not** open a public issue for a vulnerability, in the website or in Outflare. Report it privately through GitHub's "Report a vulnerability" button on this repository's or the engine's Security tab, or email hello@outflare.ai. We aim to acknowledge reports within three working days.
