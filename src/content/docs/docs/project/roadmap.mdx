Outflare is built in public, one pull request per step. v1 is the **sequencer core**: everything a team needs to replace a hosted cold-email tool with one they run themselves. The source of truth is [`docs/roadmap.md`](https://github.com/outflareai/outflare/blob/main/docs/roadmap.md) in the main repository.
