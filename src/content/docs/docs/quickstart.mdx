This gets a local instance running with Docker Compose. If you'd rather not run it yourself, [sign up](https://app.outflare.ai/signup) for the hosted app instead. It's free during early access.

You need [Docker](https://docs.docker.com/get-docker/) with the Compose plugin, `git` and `openssl`.

<Steps>

1. **Clone the repository**

    ```sh
    git clone https://github.com/outflareai/outflare
    cd outflare
    ```

    <Aside type="note">
    While v1 is being built, the newest code is on open pull requests that have not reached `main` yet. If `deploy/` is missing after cloning, check out the branch of the newest [open pull request](https://github.com/outflareai/outflare/pulls) with `git checkout <branch>`.
    </Aside>

2. **Create your settings file**

    ```sh
    cp deploy/.env.example deploy/.env
    echo "OUTFLARE_SECRET_KEY=$(openssl rand -base64 32)" >> deploy/.env
    ```

    Open `deploy/.env` and change `POSTGRES_PASSWORD`. `OUTFLARE_SECRET_KEY` encrypts mailbox passwords at rest. Compose refuses to start without it.

    <Aside type="caution">
    Back up `OUTFLARE_SECRET_KEY` together with your database. If the key is lost, stored mailbox credentials cannot be read and every mailbox has to be imported again.
    </Aside>

3. **Start it**

    ```sh
    docker compose -f deploy/docker-compose.yml up -d
    curl localhost:8080/readyz
    ```

    `readyz` returns `{"status":"ok"}` once the engine can reach Postgres. The engine runs its database migrations on start.

4. **Create the first user and workspace**

    Open [http://localhost:8080](http://localhost:8080). The first visit runs setup: you enter your name, email, a password of at least 10 characters and a workspace name, and you become the workspace owner. Setup only works while the instance has no users.

5. **Import your mailboxes**

    Go to **Mailboxes → Import CSV** and upload the file your inbox reseller gave you. The only required columns are `email` and `password` (an app password). Each mailbox is signed in to over SMTP and IMAP, and each domain's SPF, DKIM and DMARC are checked. See [Import mailboxes](/docs/guides/import-mailboxes/) for every column that is recognised.

6. **Create an API token and call the API**

    Go to **API tokens**, create a token with the `mailboxes.read` scope, and copy it. It starts with `oft_` and is shown once.

    ```sh
    export OUTFLARE_TOKEN=oft_...
    export WS=your-workspace-id   # listed under "workspaces" in GET /v1/me

    curl localhost:8080/v1/workspaces/$WS/mailboxes \
      -H "Authorization: Bearer $OUTFLARE_TOKEN"
    ```

</Steps>

## Finding your way

The sidebar starts with what you check every day, **Home, Inbox, Missions and Projects**, then one entry per module. Open a module and its pages show beneath it, and it stays open until you close it with its arrow; it reopens on the page you used last. Hover any page and click the pin to keep it under **Pinned** at the top (on a phone, pin from **All tools**).

- **Outreach**: sequences, leads, lead lists and suppression.
- **Sending**: infrastructure plans, mailboxes, domains, warm-up, sending servers, allocation, and teams and senders.
- **Analytics**: outcomes and cost per meeting, sending reports, website analytics and SEO.
- At the bottom, **All tools** explains each one and links to its guide, **Connectors** connects the services Outflare uses, and **Settings** holds the workspace, its members, API tokens, webhooks, the audit log and your account.

Press <kbd>⌘K</kbd> (<kbd>Ctrl+K</kbd>) to jump anywhere, or <kbd>G</kbd> then a letter, such as <kbd>G</kbd> <kbd>S</kbd> for sequences.
