Outflare is an open-source go-to-market platform that people and AI agents share. Connect the tools you already use, see what's working across your website, search and campaigns, and let your agents do the work through one API. Use the hosted app, Outflare Cloud, or run it yourself: self-hosted, everything lives in your own Postgres. Either way the web app, the SDKs, your scripts and your agents all use the same documented API. What is open source and what is Cloud only is on [Open source and Cloud](/docs/project/open-source-and-cloud/).

## What you can do today

- **Start in minutes.** Use the hosted app at [app.outflare.ai](https://app.outflare.ai/), free during early access ([sign up](https://app.outflare.ai/signup)), or [self-host](/docs/self-hosting/docker-compose/) the engine, web app and Postgres with one Docker Compose file.
- **See your marketing in one place.** [Website analytics](/docs/integrations/analytics/) from Google Analytics, Search Console, PostHog and more, side by side, [SEO](/docs/integrations/seo/) from Ahrefs or DataForSEO, [AI visibility](/docs/guides/ai-visibility/), [paid media](/docs/integrations/paid-media/), [social](/docs/guides/social/) and [outcomes and cost](/docs/guides/outcomes/).
- **Know every customer.** [Customer records](/docs/guides/customer-records/) for every person and company, filled by [website tracking](/docs/guides/website-tracking/), your CRM, Stripe and your campaigns, with [who can be emailed](/docs/guides/who-can-be-emailed/) worked out for each one.
- **Run email.** [Cold email sequences](/docs/guides/sequences/) across hundreds of mailboxes with [sending domains](/docs/guides/sending-domains/) checked daily, one [inbox](/docs/guides/inbox/) for every reply, and [lifecycle email](/docs/guides/lifecycle-email/) from your own Amazon SES, Postmark or Resend account.
- **Hand work to agents.** [Connect Claude, ChatGPT or Cursor](/docs/agents/connect/) with one URL, or give Outflare's own agent a goal as a [mission](/docs/agents/missions/), with approvals and send and spend limits you set.
- **Run several businesses** from one workspace with [brands](/docs/guides/brands/), or every client in its own workspace with [agency mode](/docs/guides/agencies/).

## Where the code lives

The open-source engine is published at [outflareai/outflare](https://github.com/outflareai/outflare), one commit per release. Outflare Cloud's own code is private. These docs live in [outflareai/website](https://github.com/outflareai/website); every page has an "Edit page" link at the bottom.

| Path in the repo | What it is | License |
| --- | --- | --- |
| `engine/` | Go engine: API, job queue, sending, inbox sync, policy check | AGPL-3.0 |
| `api/openapi.yaml` | The API contract that SDKs and these docs are generated from | AGPL-3.0 |
| `web/` | React web app | AGPL-3.0 |
| `mcp/` | MCP server for agents | Apache-2.0 |
| `sdk/ts/`, `sdk/python/` | TypeScript and Python SDKs | Apache-2.0 |
| `deploy/` | Docker Compose for self-hosting | AGPL-3.0 |
| `docs/adr/` | Architecture decision records | |
