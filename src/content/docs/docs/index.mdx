Outflare is open-source go-to-market infrastructure that people and AI agents share. You run it yourself or use the hosted app, Outflare Cloud. Self-hosted, it keeps your mailboxes, leads and send history in your own Postgres, and every client (the web app, the SDK, your scripts and your agents) uses the same documented API.

The first module is a **cold-email sequencer** built for teams that buy inboxes in bulk: connect hundreds of reseller mailboxes on Google Workspace or Microsoft 365 at once, run multi-step sequences across mailbox pools, and send every email through one suppression and policy check.

<Aside type="caution" title="Early development">
Outflare is being built in public. Workspaces, access control and bulk mailbox connection work today. Lead import, sequences, sending and the reply inbox are next. Pages for features that are not built yet are marked **Planned** and describe the intended design, so you can give feedback before it ships. See [Status and roadmap](/docs/project/roadmap/).
</Aside>

## What you can do today

- Use the hosted app at [app.outflare.ai](https://app.outflare.ai/). It's free during early access: [sign up](https://app.outflare.ai/signup), or [sign in](https://app.outflare.ai/) if you have an account.
- [Self-host](/docs/self-hosting/docker-compose/) the engine, web app and Postgres with one Docker Compose file.
- Create a workspace, [invite teammates with roles](/docs/guides/workspaces-and-access/), and read the audit log of every change.
- [Bulk import mailboxes](/docs/guides/import-mailboxes/) from your reseller's CSV. Each one is signed in to over SMTP and IMAP, and each sending domain's SPF, DKIM and DMARC are checked.
- Create [scoped API tokens](/docs/api/authentication/) for scripts and agents, and call the [REST API](/docs/api/) described by an OpenAPI 3.1 contract.

## Where the code lives

All of the product is in one public repository, [outflareai/outflare](https://github.com/outflareai/outflare). These docs live in [outflareai/website](https://github.com/outflareai/website); every page has an "Edit page" link at the bottom.

| Path in the repo | What it is | License |
| --- | --- | --- |
| `engine/` | Go engine: API, job queue, sending, inbox sync, policy check | AGPL-3.0 |
| `api/openapi.yaml` | The API contract that SDKs and these docs are generated from | AGPL-3.0 |
| `web/` | React web app | AGPL-3.0 |
| `sdk/ts/` | TypeScript SDK | Apache-2.0 |
| `deploy/` | Docker Compose for self-hosting | AGPL-3.0 |
| `docs/adr/` | Architecture decision records | |
