## New

- **Open source** · Self-hosting: Self-hosting: a Docker image and a docker-compose bundle that run Outflare with only Postgres.
- **Open source** · Agents and missions: Connect your AI: Claude, ChatGPT, Cursor and VS Code connect to the hosted MCP server with one URL and a consent screen, with spending off by default.
- **Open source** · Agents and missions: Projects with briefs, company context and agent memory, and agent missions that wait for your approval.
- **Open source** · Outreach: Mailboxes over Google, Microsoft 365 and SMTP/IMAP, sequences with a policy check on every email, and an inbox that sorts replies.
- **Open source** · SEO: Site audits: prove you own a site and OutflareBot crawls it, obeying robots.txt and backing off when the site struggles.
- **Open source** · API, SDK, MCP and CLI: The REST API, the TypeScript and Python SDKs, the MCP server and the outflare command line client.
- **Open source** · Workspace and settings: Request logs: every API call in a workspace with status, duration and who made it, with live follow and export.
- **Open source** · Connectors: Connectors with OAuth or your own API keys, including analytics and SEO sources, and outgoing webhooks.
